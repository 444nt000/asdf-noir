# asdf-noir

[![Builds, tests & co](https://github.com/444nt000/asdf-noir/actions/workflows/workflow.yml/badge.svg)](https://github.com/444nt000/asdf-noir/actions/workflows/workflow.yml)

[Noir](https://noir-lang.org) plugin for asdf version manager

## Prerequirements

- Make sure you have the required dependencies installed:
  - curl
  - git
  - tar

## Installation

```bash
asdf plugin add noir https://github.com/444nt000/asdf-noir.git
```

## Usage

Check [asdf](https://github.com/asdf-vm/asdf) readme for instructions on how to install & manage versions.

Notes:

- `latest` is the release marked "Latest" on GitHub (same as `noirup`), not necessarily the highest tag.
- Nightlies are not listed but can be installed by name, e.g. `asdf install noir nightly-2026-10-03`.
